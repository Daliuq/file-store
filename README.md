# ZFile 毕设修改版

这是一个基于开源网盘项目 **ZFile** 二次开发的毕业设计项目，主要修改和开发工作完成于 2024 年。项目保留了 ZFile 原有的多存储源文件管理基础，并围绕毕业设计需求增加了索引、历史版本与分享管理相关功能。

## 上游项目

- 项目： [zfile-dev/zfile](https://github.com/zfile-dev/zfile)
- 本项目基于上游 **ZFile 4.1.5** 代码进行修改。

## 主要修改

- 增加文件索引相关的数据结构与后端处理，用于组织存储源中的文件和目录。
- 增加文件历史版本及备份记录相关功能，并补充上传文件长度等记录信息。
- 扩展分享链接和用户分享管理接口，支持查询分享记录及相关文件信息。
- 根据毕业设计实现过程对部分后端控制器和服务进行调整。

这是 2024 年的毕业设计代码归档，主要用于展示当时的项目实现与修改内容。
