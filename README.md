

本项目以开源网盘项目 **ZFile** 为上游，在此基础上进行二次开发，作为 2024 年毕业设计项目。上游提供了多种存储源接入和文件浏览等基础能力；本项目的修改重点是围绕用户、文件索引、历史版本和分享管理扩展后端功能。

## 上游项目

- 上游： [zfile-dev/zfile](https://github.com/zfile-dev/zfile)
- 基础版本：ZFile 4.1.5（见 `pom.xml`）
- 本仓库是毕业设计期间的修改版，不是上游项目的官方发行版本。

## 我们做的修改

以下内容根据仓库从 2024-01-06 至 2024-05-31 的 Git 提交记录及当前代码整理。

- **文件索引与目录关系**：新增 `inode`、`inode_link` 等数据模型和对应服务，将存储源中的文件、目录及父子关系记录到数据库；补充文件所有者、大小、时间和链接等元数据，并在文件操作过程中维护索引。
- **历史版本与备份记录**：增加文件历史记录模型、操作记录逻辑和查询接口；记录历史文件的名称、大小等信息，并调整上传流程，使备份记录能够取得上传文件长度。相关索引和历史记录逻辑在后续提交中持续修复。
- **用户与个人文件空间**：增加用户管理和用户文件相关接口、用户与文件归属关系，以及用户根目录（Root Inode）管理。
- **分享功能扩展**：实现用户间文件分享和分享链接管理，保存分享对象、接收用户、有效期及访问密钥等信息；补充分享记录查询接口。
- **文件内容识别尝试**：提交记录中加入了文本分类和图片识别相关处理，并接入百度图像识别 API；相关异步处理使用消息队列组件。
- **数据库结构调整**：增加 MySQL 迁移脚本，覆盖 inode、历史记录、用户、根目录、分享及分享链接等表和字段。
- **存储操作适配**：调整部分存储源上下文、文件操作和本地临时空间处理逻辑，使其配合新增索引及文件管理流程。

## 开发记录

Git 提交记录显示，新增索引及历史记录的工作主要从 2024 年 1 月开始，随后继续完善用户、根目录、分享、内容识别和数据库迁移等部分；最后一批项目开发提交在 2024 年 5 月。README 中的功能归纳以提交记录和当前代码为准。
